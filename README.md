# Kewa — Asal Dianat · Styling & Couture

**Live site: https://msheikhattari.github.io/kewa-design/**

This repository holds the website. The site is served from the `gh-pages`
branch — anything pushed there goes live within a minute or two.

## Adding photos (hi Asal 👋)

1. Click the branch dropdown at the top left (it says `main`) and switch to
   **`gh-pages`**.
2. Open the **`photos`** folder.
3. **Add file → Upload files**, drag your photos in, and press the green
   **Commit changes** button.

That's it. Name files descriptively if you can (`bridal-01.jpg`,
`couture-gown-02.jpg`) so each look gets the right caption on the site.

## Requesting changes to the site

Open the **Issues** tab (top of this page) and comment on
**"Site changes & feedback"** (issue #1). Write requests in plain words —
"make my name bigger", "change the about text to…", "add a prices section" —
and they'll be picked up and made.
