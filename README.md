# Kewa — Asal Dianat · Styling & Couture

**Live site: https://msheikhattari.github.io/kewa-design/**

This repository holds the website. The site is served from the `gh-pages`
branch — anything pushed there goes live within a minute or two.

## Photos & change requests (hi Asal 👋) — from your phone

Everything happens in one place:
**[Issue #1 — Site changes & feedback](https://github.com/msheikhattari/kewa-design/issues/1)**. Bookmark it.

- **Send photos:** write a comment and attach photos straight from your
  camera roll (the image/paperclip button in the comment box). Say what each
  look is — "these two are bridal", "this is from the studio collection".
- **Ask for changes:** comment in plain words, like a text message —
  "make my name bigger", "change the about text to…", "add prices".

Requests are checked several times a day, made, and go live automatically.

<details>
<summary>Uploading photo files directly (optional, works best on a computer)</summary>

1. Switch the branch dropdown (top left) from `main` to **`gh-pages`**.
2. Open the **`photos`** folder.
3. **Add file → Upload files**, drag photos in, press **Commit changes**.
</details>
